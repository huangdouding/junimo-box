# Junimo Box 更新日志

## 1.2.2 - 信息架构与布局重构版

### 重构
- 全面重构六个页面的信息架构与布局，统一页面骨架为"主模块 + 次要模块 + 辅助模块"，消除空白区域和结构不一致问题。
- 重做 Overview 页面：顶部新增快捷操作栏（启动 SMAPI、选择路径、扫描 Mods、启动原版），底部新增状态信息栏（SMAPI 版本、游戏路径、当前配置），中间保持环境与 Mod 概览面板。
- 重构 Tools 页面：将散乱的平铺卡片按功能重新分组为"日常操作"、"备份与维护"、"环境管理"、"安装与导入"、"结果与记录"五大区域，每个区域带分组标头和图标。
- 改进 Logs 页面空状态：不再仅显示单张空卡片，新增双列辅助模块（"日志有什么用？"说明卡 + "打开日志文件夹"快捷操作卡）。
- 改进 Settings 页面分组：添加组标头分隔"基础设置"与"Nexus Mods"两大区块。
- 改进 Profiles 页面：添加组标头统一页面骨架风格。

### 样式
- 新增 Overview 操作栏、底部 chips、分组标头、设置标签等全套 CSS。
- 优化了 CSS 变量引用的一致性，全局使用新的色调（绿色 `--green-bg: #5e9360`、页面背景 `--bg-page: #f4efe7`）。
- 所有颜色、圆角、阴影使用 CSS 变量，方便后续主题定制。

### 修复
- 修复部分页面在 820px 以下断点的布局溢出问题。
- 修复因多处 `</div>` 不匹配导致的构建警告。
- 清理未使用的 CSS 规则和 JavaScript 声明（`currentViewMeta`、`handleDetectPath` 等），减少产物体积。

### 优化
- 页面布局统一为三栏骨架（sidebar 218px / content auto / right-panel 270px），响应式三档断点（1320px / 1200px / 820px）。
- 所有操作按钮、状态 badge、筛选 chip 使用统一视觉体系，减少各视图之间的风格差异。
- 移除所有页面顶部大卡片/介绍卡片，避免重复信息分散注意力。
- 产物优化：JS 减少约 15%，CSS 减少约 10%。

## 0.9.0 - 回收站、备份与配置加固

### 新增
- 新增回收站管理面板，支持扫描查看已删除 Mod、还原、永久删除、清空回收站。
- 新增备份与恢复功能，可导出当前 Mod 启用状态（已启用/已禁用）到 JSON 文件，并随时还原。
- 新增安装历史导出为 JSON 文件功能。
- 新增 `list_deleted_mods`、`restore_deleted_mod`、`permanently_delete_mod`、`empty_recycle_bin`、`export_mods_backup`、`import_mods_backup` 六个 Tauri 命令。

### 优化
- 优化 Profile 导入验证：检查 `app` 和 `version` 字段，非 Junimo Box 来源或版本不匹配时显示警告。
- 优化 Profile 导入安全：自动过滤包含 `/` 或 `\` 的文件夹名称，防止路径遍历攻击。
- 优化 Mod 删除流程：删除前确认对话框说明更清晰。

### 修复
- 修复回收站文件夹名称中包含非法字符时可能导致的还原失败。
- 修复 Profile 导入时缺少文件格式版本检查的问题。

### 已知问题
- 回收站列表暂不支持搜索和批量操作。
- 备份还原仅调整 Mod 启用/禁用状态，不备份 Mod 文件本身。
- Profiles 导入版本校验仅显示警告，仍可继续导入。

## 0.8.0 - 下载管理队列版

### 新增
- 新增下载队列系统，支持多个下载排队、实时进度显示、速度显示。
- 新增下载队列浮动按钮，右下角显示活跃下载数量，点击展开队列面板。
- 新增下载队列面板，支持查看每个下载的任务状态、进度条、速度和字节数。
- 新增下载重试、删除单个任务、清除已完成任务功能。
- 新增下载队列崩溃恢复，应用重启后自动恢复未完成的下载任务。
- 新增版本对比标签，ZIP 安装冲突检测时显示更新/降级/版本相同标签。
- 新增 `cancel_download` Tauri 命令，支持取消正在进行的下载。

### 优化
- 重构 URL ZIP 下载和 NXM 下载流程，走统一下载队列，不再阻塞 UI。
- 重构下载进度通知，每 1MB 发射一次进度事件，前端实时更新。
- 优化 ZIP 安装冲突行，增加版本差异彩色标签，方便判断是否需要更新。

### 修复
- 修复 URL 下载中按钮不可用的问题，现可同时添加多个下载到队列。

### 已知问题
- 暂不支持 Nexus / CurseForge 页面链接自动解析。
- 暂不支持 GitHub Release 页面自动识别。
- 下载队列暂不支持暂停/恢复功能。
- 下载队列重启恢复后，进度条从 0 开始（重新连接后继续）。

## 0.7.0 - 视觉统一与 NXM 认证版

### 新增
- 新增 Nexus Personal API Key 管理，可在设置页面保存并测试 API Key。
- 新增 NXM 协议自动下载，支持解析 nxm:// 链接并通过 Nexus API 直接下载 Mod。
- 新增 Mod 更新检测，读取 manifest.json 的 UpdateKeys，识别 Nexus/GitHub/ModDrop 更新源。
- 新增安装冲突处理，安装时检测到已存在 Mod 可选择跳过或替换（含自动备份）。
- 新增安装历史记录，追踪每次安装的来源、冲突模式、安装的 Mod 列表。
- 新增 Profiles 当前配置概念，支持标记当前配置、应用并切换、名称重命名、复制、导出、导入。
- 新增自定义确认对话框，替换原生 `window.confirm` 和 `window.prompt`，交互更统一。
- 新增 CSS 变量体系，统一管理主题配色，便于后续主题定制。

### 优化
- 优化 CSS 代码结构，合并两个重复的 `<style scoped>` 块为单一代码块。
- 优化删除 Mod 流程，确认对话框显示详细说明，降低误删除风险。
- 优化 Profiles 交互流程，新增"仅标记当前"轻量操作。
- 优化 NXM 链接解析，支持从启动参数 (nxm://) 接收链接。
- 优化 ZIP 安装冲突检测的提示信息，区分三种冲突模式。
- 优化设置页面布局，API Key 输入支持密码模式切换显示/隐藏。

### 修复
- 修复 NXM 大文件下载超时问题，支持多线程分片下载。
- 修复 NXM 链接解析可能遗漏 user_id 参数的问题。
- 修复 ZIP 安装同包内多个 Mod 的冲突检测逻辑。
- 修复部分场景下 SMAPI 日志读取失败的问题。
- 修复 Profiles 编辑器在外层滚动和内部滚动同时出现的问题。

### 已知问题
- URL ZIP 安装暂只支持直接 ZIP 下载链接，不支持网页页面解析。
- 暂不支持 Nexus / CurseForge 页面链接自动解析。
- 暂不支持 GitHub Release 页面自动识别。
- 更新检测仅显示来源，暂不支持一键自动更新。
- Profiles 导入文件格式暂未做严格版本校验。
