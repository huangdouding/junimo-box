# Junimo Box 更新日志

## 0.1.0 - 本地测试版

### 新增
- 支持选择 Stardew Valley 游戏目录。
- 支持检测 Stardew Valley、SMAPI 和 Mods 文件夹。
- 支持启动 SMAPI。
- 支持启动原版 Stardew Valley。
- 支持扫描本地 Mods。
- 支持递归扫描分类文件夹。
- 支持启用 / 禁用 Mod。
- 支持 Mod 搜索和筛选。
- 支持 Mod 类型标签。
- 支持 Mod 详情面板。
- 支持依赖检测。
- 支持 SMAPI 日志查看和基础诊断。
- 支持导出 Mod 列表。
- 支持导出问题报告。
- 支持 ZIP Mod 预览。
- 支持拖拽 ZIP Mod 进行预览。
- 支持 ZIP Mod 安装。
- 支持 ZIP 安装前依赖预览。
- ZIP 安装改为先解压到临时目录，降低安装失败污染 Mods 文件夹的风险。
- 新增配置方案 Profiles v0.1。

### 已知问题
- 配置方案 Profiles 的交互还比较粗糙。
- UI 和整体交互还需要专门优化。
- 暂未支持在线下载 Mod。
- 暂未支持 Mod 更新检测。
