# Junimo Box 更新日志
## 0.3.0 - 启动器与配置方案增强测试版

### 新增
- 新增一键下载 SMAPI 安装包功能。
- 新增自动打开 SMAPI 官方 Windows 安装器功能。
- 新增 SMAPI 安装完成后的重新检测流程。
- 新增 SMAPI 版本显示。
- 新增启动前环境检查。
- 新增 Profiles 重命名功能。
- 新增 Profiles 复制功能。
- 新增 Profiles 单个配置导出功能。
- 新增 Profiles 全部配置导出功能。
- 新增 Profiles 配置导入功能。

### 优化
- 优化 SMAPI 下载流程，支持远程下载源配置。
- 优化 SMAPI 下载失败时的兜底逻辑。
- 优化 SMAPI 下载状态提示，显示读取下载源、下载、解压和打开安装器等阶段。
- 优化 SMAPI 下载稳定性，增加超时和空文件检查。
- 优化 SMAPI 下载速度，支持多线程分片下载。
- 优化 SMAPI 安装流程，不再将“打开安装器”误判为“安装完成”。
- 优化 Profiles 配置管理流程，支持更方便地派生和分享配置方案。
- 优化 Profile 编辑卡片滚动结构，避免外层和列表同时滚动。

### 修复
- 修复 SMAPI 下载过程中可能出现 0KB 文件的问题。
- 修复 SMAPI 下载时界面可能长时间无响应的问题。
- 修复 GitHub API 限流导致无法获取 SMAPI 最新版本的问题，改为远程配置文件加内置兜底链接。
- 修复 Profile 编辑卡片在部分版本中再次出现双滚动的问题。

### 已知问题
- SMAPI 下载速度仍取决于用户网络环境和下载源访问情况。
- Profiles 导入文件格式暂未做严格版本校验。
- 在线 ZIP 链接安装暂未支持。
- Mod 更新检测暂未支持。
- UI 仍需要继续向最终概念图方向优化。

## 0.2.0 - 交互优化测试版

### 新增
- 新增 Profiles 新建 / 编辑小卡片交互。
- 新增 Mod 详情小卡片交互。
- 新增 ZIP Mod 安装预览小卡片交互。
- 新增分级消息提示，区分成功、普通信息、警告和错误。
- 新增更清晰的 Profiles 配置编辑流程，可在配置页面直接勾选 Mod。

### 优化
- 优化 Profiles 页面布局，页面默认更轻量。
- 优化 Profiles 配置卡片展示，默认不再展开全部 Mod。
- 优化工具箱页面结构，按文件夹、导出、ZIP 安装进行分组。
- 优化 Mod 列表卡片密度，减少冗余信息。
- 优化 Mod 列表滚动结构，Mods 页面外层不滚动，只保留 Mod 列表内部滚动。
- 优化 Profile 编辑卡片滚动结构，避免卡片外层和列表内部双滚动。
- 优化小卡片交互，Profiles、Mod 详情、ZIP 预览保持统一的打开 / 关闭方式。
- 优化 ZIP 拖拽预览入口，拖拽后以独立卡片展示预览内容。
- 优化整体提示反馈，错误、警告和成功状态更容易区分。

### 修复
- 修复 Mods 页面外层滚动条和 Mod 列表内部滚动条同时出现的问题。
- 修复 Profile 编辑卡片出现双滚动的问题。
- 修复部分页面信息过长时挤压主要操作区域的问题。
- 修复工具箱功能入口混杂、层级不清的问题。

### 已知问题
- Profiles 仍处于实验阶段，后续还需要继续优化应用前预览和配置差异显示。
- 在线 ZIP 链接安装暂未支持。
- Mod 更新检测暂未支持。
- UI 仍需要继续向最终概念图方向优化。

## 0.1.0 - 本地测试版

### 新增
- 支持选择 Stardew Valley 游戏目录。
- 支持检测 Stardew Valley、SMAPI 和 Mods 文件夹。
- 支持启动 SMAPI。
- 支持启动原版 Stardew Valley。
- 支持扫描本地 Mods。
- 支持递归扫描分类文件夹。
- 支持启用 / 禁用 Mod。
- 支持 Mod 搜索和筛选。
- 支持 Mod 类型标签。
- 支持 Mod 详情面板。
- 支持依赖检测。
- 支持 SMAPI 日志查看和基础诊断。
- 支持导出 Mod 列表。
- 支持导出问题报告。
- 支持 ZIP Mod 预览。
- 支持拖拽 ZIP Mod 进行预览。
- 支持 ZIP Mod 安装。
- 支持 ZIP 安装前依赖预览。
- ZIP 安装改为先解压到临时目录，降低安装失败污染 Mods 文件夹的风险。
- 新增配置方案 Profiles v0.1。

### 已知问题
- 配置方案 Profiles 的交互还比较粗糙。
- UI 和整体交互还需要专门优化。
- 暂未支持在线下载 Mod。
- 暂未支持 Mod 更新检测。
